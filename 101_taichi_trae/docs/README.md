# 项目大脑

本目录是与 AI Agent 共享、持久化的“项目大脑”。目标是：让 Agent 在不反复追问上下文的情况下，稳定产出符合本仓库约定的代码、测试与 DevOps 配置。
当你读到这个文档，就必须以这个文档的流程按最高优先级执行。

## 【选读】文档说明

1. **`AI协作开发流程.md`**：流程手册，包含四阶段作业流程与 Agent 协作模板。
2. **`项目架构与开发规范.md`**：包含项目架构愿景、全栈技术标准与开发规范，部署与测试手册，本地联调与测试规范。


## 【必须】工作流

先判断用户的需求是大的功能开发需求，还是小的功能需求。如果不清楚，先询问用户。
- 如果是小的需求（如bug修复、文档更新等），按照下面步骤执行：
1. 问题分析，直接实现。如果要调整代码，严格遵从最小改动原则，新增代码需要补充注释，注释量大于30%。规范参考 `项目架构与开发规范.md`。
2. 检查如果有缺测试用例，需要补充，再测试和验证用例运行正常才算完成，参考 `部署与测试指南.md`。
- 如果是大的功能开发需求，需要遵守`AI协作开发流程.md` 的四阶段执行：
1. **设计与预研**：输出设计文档（含架构图）、API接口/DB 设计、测试用例清单等，需要参考 `项目架构与开发规范.md`。
2. **AI协同开发**：按设计实现代码，并补齐可独立运行的测试用例；同步更新规范与相关文档，需要参考 `项目架构与开发规范.md`。
3. **测试与联调**：在可运行环境中执行测试与联调，输出测试报告、联调记录与问题修复状态。需要参考 `项目架构与开发规范.md`。
4. **知识固化**：把本次实现与验证沉淀为资产，并更新文档索引与可复用模板。

每次只执行一个阶段，每个阶段完成后，人工触发再执行下一个阶段。
